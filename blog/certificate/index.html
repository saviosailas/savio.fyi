Manage certificate and provisioning profile

Developer certificate and provisioning profile can be managed manually or it can be automatically managed by Xcode. Most of the development teams prefer to automatically manage signing for development activities and manual signing for CI/CD pipline and release build.

Steps to create developer centerificate and profile provisioning

  1. Open KeyChain Access app on mac
  2. Select Keychain Access from menu bar
  3. Keychain Access -> Certificate Assistant -> Request a Certificate From a Certificate Authority
  4. Enter user email, name andd choose "save to disk"
